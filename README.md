# 🚀 Welcome to NexEagle

## 🧠 Project Overview

**NexEagle** is an **AI-powered healthcare OS** designed for clinics and hospitals across India.  
It enables faster patient processing, improved efficiency, and complete digital transformation using AI-driven tools like **EasyHMS**, **Doc-E AI**, and **EasyPharm**.

---

## ⚙️ Tech Stack

This project is built with:

- ⚡ **Vite** – Fast and modern development environment  
- ⚛️ **React + TypeScript** – Component-based architecture for scalability  
- 🎨 **Tailwind CSS** – Utility-first styling for rapid UI development  
- 🧩 **shadcn/ui** – Beautifully designed React components
